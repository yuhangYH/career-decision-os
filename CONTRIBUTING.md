# Contributing

Thanks for helping improve Career Decision OS.

## Before opening a change

1. Use fictional or clearly anonymized candidate examples.
2. Link job records to an employer-operated careers page or official ATS.
3. Keep uncertain, closed, stale, and discovery-only states explicit.
4. Add or update tests for behavior changes.
5. Run `pnpm check` and `pnpm validate:sources`.

Never commit CVs, contact details, application notes, screenshots containing personal data, API keys, tokens, or local user paths. The automated public-content audit is a safety net, not a substitute for reviewing the diff.
